FlyRank ML Internship Capstone

Content Decline Prediction for Search Intelligence

A machine-learning approach to ranking content pages for human review when editorial capacity is limited.

Author: Sushmita Mishra   ·   Lane: Refresh / Content Opportunity Scoring

Abstract

This project investigates whether search performance, content, freshness, and engagement signals can be used to identify content pages that satisfy a predefined decline label. A client-holdout evaluation was used to compare Logistic Regression, Decision Tree, and Random Forest models against a transparent baseline. Random Forest achieved the strongest ranking performance, reaching 0.74 Precision@50 compared with 0.24 for the baseline. The final model was used to produce a ranked content-review queue with predicted probabilities, confidence information, suggested actions, and reason codes. The resulting system is intended as decision support for human editorial investigation rather than an automatic refresh decision or a causal explanation of search performance.

1. Problem

Content teams may have many pages available for review but limited editorial capacity. The practical question is therefore not simply whether a page is declining, but which pages should receive attention first.

This project addresses that prioritization problem by producing a ranked review queue based on predicted decline probability.

A human editor can investigate the highest-ranked pages and decide whether further performance analysis, a potential refresh, or monitoring is appropriate.

2. Data

The analysis uses the anonymized FlyRank ML Internship dataset. The modeling workflow combines search-performance, content, freshness, visibility, and engagement signals.

Model features

Numeric features include search volume, competition, CPC, content length, historical impressions, clicks, sessions, days with impressions or sessions, content age, days since update, CTR, average position, engagement rate, scroll rate, and AI traffic percentage.

Categorical features include competition level, content type, main intent, age tier, freshness tier, word-count tier, impression tier, and position tier.

Data safety

Pseudonymous IDs were not used as predictive features. Label-derived trend fields were also excluded from the final feature set to reduce leakage risk.

No client names, domains, URLs, private queries, credentials, or raw private exports are included in this public paper.

3. Methodology

Target

The target is is_declining_label, representing whether a content item satisfies the predefined decline criteria used by the feature-preparation pipeline.

Models

  • Logistic Regression
  • Decision Tree
  • Random Forest

Validation

The evaluation uses a client-holdout split with 27,675 training rows and 2,325 test rows. The test-set positive rate is approximately 54.2%.

Precision@50 is emphasized because the intended application is prioritizing a limited number of pages for review.

5. Limitations

  • The model predicts the predefined decline label; it does not predict future Google rankings.
  • The results show associations rather than causal relationships.
  • A high decline probability does not prove that refreshing a page will improve future performance.
  • Individual recommendations require human investigation.
  • The measured performance reflects the available evaluation dataset and client-holdout design.
Important: This project should be interpreted as measured, directional decision support — not as a causal model of Google's ranking system.

6. Ranked Recommendations

The final Random Forest produces a ranked content-review queue using predicted probability of the positive is_declining_label.

Higher predicted probability indicates higher priority for human review.

Action framework

  • Review first: high predicted decline risk.
  • Refresh investigation: high decline risk combined with evidence of stale content.
  • Performance investigation: high decline risk combined with weakening search or engagement signals.
  • Monitor: lower-risk content that does not require immediate review.

These actions are recommendations for human investigation. The model score alone does not establish that a refresh will improve future performance.
